# Sudoku

## Features:
* The game itself
* Solver
* Check Answer
* 3 levels
* 4x4, 6x6 or 9x9 board



## How to run?
Clone this repo sudoku/@eetsucodes
cd into /sudoku/
run ´npm run dev´ to start the game :)
Game can be found in your browser in address "localhost:3000"

Happy Solving!
